# Ejercicios básicos

Veinte prácticas progresivas para empezar a programar JavaScript en páginas web. Conoce primero HTML elemental, atributos, formularios y selectores CSS. Lee el README de cada ejercicio antes de completar `app.js`.

Cada carpeta tiene `index.html`, `main.css`, `app.js` con tareas y `README.md`. Las [soluciones](soluciones/README.md) reproducen la misma estructura y funcionan por separado.
