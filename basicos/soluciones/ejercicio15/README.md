# Solución 15: Objetivo de ahorro con while

[Enunciado y teoría](../../ejercicio15/README.md) · [Índice de soluciones](../README.md)

## Cómo leer esta solución

Primero identifica los datos y las referencias al DOM en `app.js`. Después sigue cada evento y observa cómo el cálculo o el cambio de estado termina en la presentación. Compara esta implementación con tus decisiones; hay varias soluciones correctas.

`while` repite instrucciones mientras una condición sea verdadera. Resulta útil si no conocemos de antemano cuántas repeticiones necesitaremos. El estado debe avanzar en cada vuelta para alcanzar una condición de salida.

## Verificación

- Meta 100 y aportación 30 → 4 meses y 120 €.
- Meta 20 y aportación 20 → 1 mes; aportación 0 se rechaza.

Arranca el servidor desde la raíz y abre `http://localhost:8000/basicos/soluciones/ejercicio15/`. La solución incluye su propio HTML, CSS y datos para poder ejecutarse por separado. No copies solo `app.js` si hay módulos o archivos auxiliares.
