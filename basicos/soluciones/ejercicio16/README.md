## Cómo leer esta solución

Primero identifica los datos y las referencias al DOM en `app.js`. Después sigue cada evento y observa cómo el cálculo o el cambio de estado termina en la presentación. Compara esta implementación con tus decisiones; hay varias soluciones correctas.

Un array es una colección ordenada de valores. Los índices empiezan en cero: el primer elemento es `lista[0]` y el último es `lista[lista.length - 1]`. `.length` expresa la cantidad de elementos, no el último índice.

## Verificación

- Se ven Cuaderno, Lápiz y Regla, en ese orden.
- Cantidad 3; primero Cuaderno, último Regla. Repetir no duplica elementos.

Arranca el servidor desde la raíz y abre `http://localhost:8000/basicos/soluciones/ejercicio16/`. La solución incluye su propio HTML, CSS y datos para poder ejecutarse por separado. No copies solo `app.js` si hay módulos o archivos auxiliares.
