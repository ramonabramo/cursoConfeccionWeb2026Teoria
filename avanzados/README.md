# Ejercicios avanzados

Esta carpeta reúne la colección original (1–20 y variantes 12A y 14base) y doce prácticas nuevas (21–32). La colección original ya incluye introducciones al DOM y a arrays; se mantiene aquí agrupada por su procedencia, aunque la dificultad no sea uniforme.

Empieza después de los [básicos](../basicos/README.md). Orden recomendado para las variantes: 12 → 12A → 13 → 14base → 14. Del 21 al 32 avanza en orden. Consulta los comentarios de cada original para saber si es un ejemplo resuelto o una plantilla pendiente.
